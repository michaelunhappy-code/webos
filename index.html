介绍

这是什么？

Chrome OS (apilio) 是一个跑在浏览器里的虚拟桌面脚本。装上它之后，你浏览的任何网页右下角都会出现一个「进入桌面模式」的按钮，点开就是一个完整的桌面环境——有任务栏、侧边栏、窗口、文件管理器、编辑器，就像在用一台小电脑。

它不是一个独立的软件，而是寄生在浏览器页面里的一层界面。所有的文件、设置、对话记录都保存在你自己浏览器的本地存储中，不会上传到任何服务器。关掉网页，桌面就消失；下次打开，数据和窗口位置都还在。

脚本最初是为了写代码、管理文件方便而做的，后来慢慢长成了一个什么都能放进去的小系统：文件管理、C++ 在线编译、Python 执行、AI 对话、Word / Excel 编辑、画板、小游戏、计算器、截图贴图……你可以把它当成一个浏览器里的「瑞士军刀」。

适合谁用？

  • 想在任何设备（包括平板、手机）上随手写代码、记笔记的人；
  • 需要一个小型文件管理器来临时整理下载内容的人；
  • 想体验「网页即系统」的折腾爱好者；
  • 需要一个随手可用的 AI 对话窗口、计算器、截图工具的人。

它的边界在哪里？

它不是真正的操作系统，不能装 exe，不能访问你电脑的本地文件系统（只能通过浏览器上传 / 下载）。它也不保证 100% 稳定——部分功能（画板、网络模块、插件）仍在迭代中，使用前请阅读脚本内的使用协议，并做好重要数据的备份。

作者是一个个人开发者，脚本免费开源，包括测试信息(/version)也都开源，没有商业化服务。如果它帮到了你，去 GitHub 点个 star 就是最好的支持。

功能

装上之后，多了这些。

文件管理

支持 txt / cpp / md / docx / xlsx / 画板 / 文件夹 等功能，拖拽上传、新建、重命名、删除，一键打包下载。

代码编辑

VSCode 风格编辑器，C++ 在线编译运行，Python 执行，代码补全和语法高亮。

AI 对话

Markdown 渲染、LaTeX 公式、上下文记忆、多模型切换，支持自定义智能体和 Cclaw 工作流。

Office 支持

内置 Word 文档编辑和 Excel 表格编辑，可导出标准 .doc / .xls 文件。

个性化

7 套主题、自定义色调、壁纸上传、明暗切换、窗口记忆、锁屏密码、时间机器历史版本。

娱乐与工具

画板、贪吃蛇、2048、扫雷、五子棋、中国象棋、斗地主，以及计算器、单位换算、IP 查询、二维码等工具。

截图与贴图

Ctrl+Shift+A 截图，支持标注、贴图、缩放、透明度、锁定和鼠标穿透。

虚拟机

可在脚本内创建独立的 Chrome OS 虚拟机，独立密码、独立磁盘，支持嵌套使用。

安全与备份

系统密码加密本地数据，支持导出明文备份、导入恢复、时间机器历史版本。

每个功能都能在脚本设置里单独开关。完整说明见脚本内「功能浏览」。

三步装好。

选择你的浏览器：

1

装一个脚本管理器

脚本需要装在用户脚本管理器里运行。推荐 Tampermonkey，ScriptCat（脚本猫）也可以。

在 Chrome 应用商店安装：

Tampermonkey · Chrome 应用商店

在 Edge 外接程序商店安装：

Tampermonkey · Edge 外接程序

在 Firefox 附加组件站安装：

Tampermonkey · Firefox 附加组件
2

允许运行用户脚本

新版 Chrome 默认不让扩展运行用户脚本，不做这一步脚本不会生效。

Chrome 138 及以上：

  1. 右键点工具栏上的脚本管理器图标（Tampermonkey 或 ScriptCat），选「管理扩展程序」。
  2. 打开「允许用户脚本」开关。

Chrome 137 及以下：

  1. 地址栏打开 chrome://extensions。
  2. 打开右上角的「开发者模式」。

Edge 默认不让扩展运行用户脚本，不做这一步脚本不会生效。

Edge 138 及以上：

  1. 地址栏打开 edge://extensions，在脚本管理器下面点「详细信息」。
  2. 打开「允许用户脚本」开关。

Edge 137 及以下：

  1. 地址栏打开 edge://extensions。
  2. 打开左侧的「开发人员模式」。

Firefox 不需要额外设置，直接下一步。

3

安装脚本

点下面的按钮，管理器会弹出安装页面，点「安装」。然后刷新任意网页，右下角出现「进入桌面模式」按钮即成功。

常见问题

装了，然后呢？

装好了，但网页没有任何变化

按顺序检查：

  1. Chrome / Edge 用户：确认做了第 2 步，这是最常见的原因。
  2. 点 Tampermonkey 图标，确认它本身和 Chrome OS (apilio) 都处于启用状态。
  3. 刷新当前网页。
  4. 如果网页本身是浏览器的内置页面（如 chrome:// 开头的页面），脚本不会运行，请换一个普通网页测试。

还是不行，可以在 GitHub Issues 反馈，写上浏览器和版本。

怎么更新？

不用管。脚本管理器会定期自动检查更新。想立刻更新，就在 Tampermonkey 管理面板里点「检查更新」，或者再点一次上面的下载按钮。

怎么关掉某个功能？

进入桌面模式后，打开「系统控制中心」，每个功能都有单独的开关。也可以直接搜索「设置」打开。

会盗号吗？收集了哪些数据？

不会。脚本本身不收集任何账号信息。AI 对话功能需要你自己配置 API Key，数据直接发送到你指定的 AI 服务商。

所有文件、设置、密码都保存在浏览器本地存储中，创作者无法远程访问。代码全部开源，可以自己看。

这是官方做的吗？

不是。这是个人独立开发的开源项目，与任何官方平台无关。使用脚本的同时也请遵守所在网站本身的规则。

我的文件会不会丢？怎么备份？

所有文件保存在浏览器本地存储（IndexedDB）中。以下操作会导致数据丢失：

  • 清除浏览器缓存 / 站点数据；
  • 卸载油猴插件；
  • 更换浏览器或设备；
  • 使用浏览器的「无痕模式」。

建议定期在「系统控制中心 → 数据管理」中点击「导出明文完整备份」，把 JSON 文件保存到电脑上。需要时再导入恢复。

如果设置了系统密码，导出的备份是明文的，请妥善保管；导入时需要验证当前密码。

为什么我的数据在刷新后不见了？

检查以下几点：

  1. 是否使用了无痕 / 隐私模式？无痕模式关闭标签页后会清空存储。
  2. 是否设置了系统密码但忘记解锁？加密数据在未解锁时不会加载。
  3. 浏览器的存储空间是否已满？可以在「系统控制中心」查看存储占用。
  4. 是否在多个标签页同时打开了桌面？多标签页同时写入可能导致冲突，建议只在一个标签页使用。

如果以上都不是，请到 GitHub Issues 反馈，附上浏览器版本和复现步骤。
